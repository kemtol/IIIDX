# 2026-05-07 21:56 WIB - BSJP 16:00 walk-forward PnL recap

- **Scope:** Inference operations / daily reporting.
- **Product:** Inference.
- **Intent:** Add a 16:00 WIB recap for the last 7 signal/trading days using actual `picks_log` rows only, without re-running models or backfilling missing signal history.

## Changes

- Added `pipeline/run/bsjp_pnl_recap.py`.
  - Reads `inferences/bsjp/db/inference.duckdb` `picks_log` for the selected variant.
  - Reads `data/Level_0_Raw/yfinance_1h.parquet` for trading-day order and T+1 10:xx WIB close exits.
  - Computes gross return as `(exit - entry) / entry`.
  - Computes net return as `gross - 0.004` by default.
  - Aggregates equal-weight top-3 daily PnL from closed picks only.
  - Marks missing signal logs as `missing picks_log`.
  - Marks signal days without a future 1h trading date as `pending exit T+1 close10`.
  - Marks unavailable entry/exit prices as missing, without imputation.
  - Supports dry-run rendering, message-file output, Telegram send, Discord send, and combined `--send`.

- Added `pipeline/run/run_pnl_recap_bsjp.sh`.
  - Uses the repo venv when available.
  - Logs to `_LOG/pnl_recap_bsjp_YYYYMMDD.log`.
  - Calls the recap helper with `--send --no-print`.

- Added tests in `pipeline/run/tests/test_bsjp_pnl_recap.py`.
  - Covers positive/negative/flat/missing PnL math.
  - Covers Friday -> Monday and holiday-style next-valid-trading-day exit mapping.
  - Covers temporary DuckDB integration with mixed closed, pending, and missing days.
  - Verifies the recap message sections and key lines.

- Installed cron entry:
