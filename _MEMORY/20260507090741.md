# 2026-05-07 09:07 WIB — BSJP Telegram heartbeat state + interval control

- **Scope:** Inference operations / preflight heartbeat.
- **Product:** Inference.
- **Intent:** Make `run_preflight_bsjp.sh` callable every minute while sending Telegram status every configurable interval, default 5 minutes. Keep verbose readiness format first, with `/compactstatus` and `/intervalstatus` available for later adjustment.

## Changes

- Added `pipeline/run/bsjp_heartbeat.py`.
  - Persists runtime state in `_STATE/bsjp_heartbeat.json`.
  - Supports Telegram command polling:
    - `/compactstatus` toggles verbose/compact status format.
    - `/compactstatus on|off` explicitly sets compact/verbose.
    - `/intervalstatus` reports current interval and format.
    - `/intervalstatus N` sets heartbeat interval to 1-60 minutes.
  - Implements interval gating via `last_sent_epoch`.
  - Formats verbose status into `T-1 CONTEXT`, `T INTRADAY`, and `PRE-COOK` sections.
  - Sends Telegram messages as plain text to avoid Markdown parsing issues from underscores in check names.

- Updated `pipeline/run/run_preflight_bsjp.sh`.
  - Calls heartbeat helper before heavy work to process Telegram commands and enforce interval gating.
  - Preserves existing check -> repair -> pre-cook -> final check flow.
  - Uses helper-generated status messages for Telegram.
  - Marks `last_sent_epoch` after each eligible heartbeat.
  - Treats `DB_` / `entry_price` failures as pre-cook triggers.

- Added tests in `pipeline/run/tests/test_bsjp_heartbeat.py`.
- Added `_STATE/` to `.gitignore`.
- Installed cron entry:
  - `* 8-15 * * 1-5 cd /home/kemal/idx && bash pipeline/run/run_preflight_bsjp.sh >> _LOG/cron_preflight.log 2>&1`
  - The script is invoked every minute, but default state sends every 5 minutes.
