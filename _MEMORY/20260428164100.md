### 3. Rust Port Attempt — `inferences/bsjp/rust/`

Status: **Blocked by tool infrastructure, not by Rust**

Attempted:
- `Cargo.toml`: polars 0.53, lightgbm 0.2, duckdb 1.105
- lightgbm-sys: needs cmake + C headers → installed cmake, but `stddef.h` missing
- Removed lightgbm/duckdb deps, kept only polars
- Minimal test (`scan_parquet + limit(10)`) fails to compile within 5-min timeout
- Root cause: polars has ~400MB of dependencies, first-time compilation takes 8+ minutes on this machine

API discovery:
- `LazyFrame::scan_parquet(path: PlRefPath, args: ScanArgsParquet)` — polars 0.53 uses `PlRefPath::new("str")`
- `col("x").abs()` → `col("x").abs()` (exists but type mismatch)
- `col("x").rank(RankMethod::Average, descending)` — takes 2 args

Rust is viable long-term but first compile is brutal on this machine.
