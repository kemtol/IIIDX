## Findings

OLD `data/_BAK/Level_2_Datamart/training_datamart_bsjp_overnight.parquet` is semantically close10:
- `label_name = bsjp_close10_sl2`
- entry = close@15 T
- exit = open@10 T+1
- 108,698 rows, 730 trading days, through 2026-04-23

NEW `data/Level_2_Datamart/training_datamart_bsjp_overnight.parquet` is true overnight:
- `label_name = bsjp_overnight_sl2`
- exit = open@09 T+1
- 110,236 rows, through 2026-04-24

The large v18 drift came from objective mismatch, not random value drift:
- `entry_price`: 0 changed rows on common OLD vs NEW keys
- `exit_price`: 85,945 / 105,102 changed rows
- `label_tp`: 32,967 / 105,102 changed rows
- `label_sl2`: 19,202 / 105,102 changed rows

   - Rebuilt close10 filtered to OLD datamart `(date,ticker)` universe
   - 108,698 rows, 260 columns, 2023-03-07 -> 2026-04-23
   - `label_name = bsjp_close10_sl2`
   - Core drift vs OLD: `exit_price` 0 rows, `label_sl2` 0 rows, `entry_price`/`label_tp` 1 row only

3. `model/BSJP/bsjp_v18_close10_rebuild/`
   - Trained with OLD v18 params on `training_datamart_bsjp_close10_rebuild_v18like.parquet`
   - `feature_prune_top_n=0`, 249 features, market execution
   - Params: `min_data_in_leaf=50`, `lambda_l1=0.5`, `lambda_l2=0.5`, `min_gain_to_split=0.01`
   - `tp_pct=0.035`, `sl_pct=-0.015`
