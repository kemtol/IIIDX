## Changes

- `pipeline/run/bsjp_pnl_recap.py`
  - Refactor `format_recap_message()`:

    - Summary compact (Net, Gross, Win, Best, Worst).
    - `LIVE PICKS — <date> (pending T+1 close10)` box table (Pick, Entry).
